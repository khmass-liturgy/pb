# 작업 인계 노트 (2026-10-13)

다른 Claude 세션이 이 저장소 작업을 이어받을 때 읽는 문서다. 규칙·구조는 `CLAUDE.md`가 기준이고,
여기에는 **진행 상태와 다음 할 일**만 적는다. 작업이 진행되면 이 문서도 같이 고친다.

## 0. 이어받는 세션이 먼저 할 일

1. `git fetch origin && git status` — 로컬에 커밋 안 한 변경이 있으면 **버리지 말고** 먼저 사용자에게
   무엇인지 확인한다(`git stash` 후 `git pull --rebase origin main`, 필요하면 `git stash pop`).
2. `main` 최신으로 맞춘 뒤 `CLAUDE.md` 전체를 읽는다(배포 규칙: 커밋 → 브랜치 푸시 → PR → 병합).
3. 아래 상태를 확인하고 사용자의 다음 지시를 기다린다.

  표기는 「인공지능 공동연구팀」으로 통일(사용자 지시 — ‘AI’ 대신 ‘인공지능’). 분류 이름도 「인공지능 공동연구팀」(저장된 옛 메뉴의 「AI공동연구팀」은 자동으로 새 이름으로 묶임).
  조류인플루엔자(AI) 뜻의 ‘AI’(예: AI관련정보 탭, AI 의심 증상)는 그대로 둔다.
- 시뮬레이터의 항목·가중치(25·20·20·25·10)와 0~4 입력은 제안서 그대로이고, 점수 구간(0~24 낮음·25~49 보통·50~74 높음·75~ 매우 높음)은
  제안서 예시(50점=높음)에 맞춘 **임시 기준**이며 검증되지 않았다 — 화면에 같은 문구를 둔다.
- 제안서가 인용한 공식 자료(농식품부 SOP 2024.9, WOAH·FAO 자료, 방역기간 4월 15일 연장)는 **원문을 확인하지 못해 ‘공고 원문 미확인’ 배지**로 표시했다.
  (이 사이트가 확인한 농식품부 2026.2.27 보도자료는 특별방역대책기간을 3월 31일까지 연장 — 이후 추가 연장 여부는 미확인.)
- 아직 연결되지 않은 것: 지역별 위험지도, 자동 위험예측, 농장별 보고서 자동 생성, 철새·GIS 자료. 연결된 공식 자료는 AI관련정보 탭의 발생·검출 현황 지도뿐이다.
- 처음부터 연구 데이터 자동 수집·다중 AI 분석을 붙이려면 별도 설계가 필요(농장 좌표·경영정보 보호, 접근권한·보존기간 포함).

## 2. 최근 완료된 기능(이 세션, 2026-10-08 ~ 10-13, 모두 main 병합)

- 유료서비스 분류 「시세 예측·분석」, 「백신·약품관리」(+ 영양제 종류별 사용요령, 백신 접종방법·종류 안내 — 관리자 편집).
