# 작업 인계 노트 (2026-10-13)

다른 Claude 세션이 이 저장소 작업을 이어받을 때 읽는 문서다. 규칙·구조는 `CLAUDE.md`가 기준이고,
여기에는 **진행 상태와 다음 할 일**만 적는다. 작업이 진행되면 이 문서도 같이 고친다.

## 0. 이어받는 세션이 먼저 할 일

1. `git fetch origin && git status` — 로컬에 커밋 안 한 변경이 있으면 **버리지 말고** 먼저 사용자에게
   무엇인지 확인한다(`git stash` 후 `git pull --rebase origin main`, 필요하면 `git stash pop`).
2. `main` 최신으로 맞춘 뒤 `CLAUDE.md` 전체를 읽는다(배포 규칙: 커밋 → 브랜치 푸시 → PR → 병합).
3. 아래 상태를 확인하고 사용자의 다음 지시를 기다린다.

## 1. 전염성기관지염(IB) 차단 AI공동연구팀 (유료서비스 최상단 `ibteam`)

- 코드: `index.html`의 `IB_*`, `ibLecture1`, `ibLecture2`, `renderIbTeamPanel`, `ibBind`, `ibRef`/`ibPm`,
  `ibLossHtml`/`ibLossBind`(손실 계산기). 편집본: Firebase `premium_content/ib_research/latest.json`.
- 진행 원칙(사용자 지시):
  - 반드시 1단계부터 순차 진행. **사용자가 「다음 단계」라고 하기 전에는 다음 단계로 넘어가지 않는다.**
  - 각 강의는 ①목표 ②기초 ③전문 심화 ④육계·산란계 비교 ⑤현장 사례 ⑥논문·국제기구 자료
    ⑦예방·관리 ⑧요약·점검 질문 ⑨다음 제안 순서.
  - 「더 깊이」「논문 분석」「현장 중심으로」 = 현재 강의 심화.
  - **모든 강의는 현장 중심으로 설계**(농장에서 무엇을 측정·조치·확인하는지, 비용 대비 실효성, 육계/산란계 분리).
  - 문헌은 실제로 확인한 것만. 카드마다 확인 수준(`ver`: full/abs/cite) 표시. PMID·DOI는 PubMed에서 확인.
    유전자형 일치로 교차방어를 단정하지 않고 혈청형·유전자형·방어형을 구분. 사실/가설/논쟁/현장 추론 배지.
  - 백신 조합·접종일령은 "국내 허가사항·농장 위험도·검사 결과로 담당 수의사와 검토" 문구 유지.
- 현재 상태: **1단계(IB 기초 질병학)**
  - 제1강 「IB란 어떤 질병인가?」 — 공개. 문헌 5건 원문 재확인(WOAH 3.3.2 2018판·Valastro 2016 전문,
    Cavanagh 2007·Jackwood 2012 초록, Schalk & Hawn 1931 2차 인용). 현장 보강(오해 6가지, 감별·신고,
    조기 경보 기준, 72시간 대응, 기록지, 손실 계산기, 모체항체 문헌 2건) 완료.
  - 제2강 「IBV는 어떤 바이러스인가?」 — 공개(현장 중심). 문헌 10건 모두 초록 확인(국내 6건:
    Kim JS 2026 IGE, Kim JY 2025 IGE(검역본부), Kim SJ 2026 Poult Sci(GX-1), Kim SJ·Choi 2026 Front Vet Sci,
    Jung 2022 Arch Virol, Lee DW 2025 Avian Dis).
  - **다음: 제3강 「IBV는 어떻게 전파되는가?」**(현장 동선 중심 — 차량·사람·기구·계란 포장재·분뇨/깔짚,
    농장 간 전파, 다일령·지속감염, 부화장, 동선도 실습). 그다음 제4강(조직 손상), 제5강(육계·산란계 피해 차이),
    5강까지 끝나면 1단계 마무리(핵심 결론 5·농장 확인 5·추가 논문·미해결 문제·넘어가기 전 확인).
- 남은 확인 과제: 제2강 논문 전문(특히 GX-1·Huang 2026 통계), 국내 시판 백신의 K-II 하위그룹·GX-1 방어 자료,
  IBV 환경 생존 원저, 잠복기 수치 원저, WOAH 3.3.2의 2018년 이후 개정 여부, 감별표의 신고 전화(1588-9060) 공식 확인.

## 2. 최근 완료된 기능(이 세션, 2026-10-08 ~ 10-13, 모두 main 병합)

- 유료서비스 분류 「시세 예측·분석」, 「백신·약품관리」(+ 영양제 종류별 사용요령, 백신 접종방법·종류 안내 — 관리자 편집).
- 관세청 수출입 통계(국내 중계 서버 `/fetch-customs`, farm-pro `sms-relay`) → `import_status/stats.json`,

- 사육 통계 분기 수집, 상단 제목·날짜 → 양계 시세통계 이동, 메뉴 아래 NEW 흐름 띠.
- 날씨예측: 이상기온 체크 멘트, 환기가이드 단계 ±1(이상고온·저온, 앙상블 확률 40%), 「오늘의 날씨 뉴스」 카드
  (`scripts/fetch_weather_news.py`, 하루 6회).
- 상황별 처방 관리: 상황 제목으로 AI가 증상·원인·해결책 요점 작성(`generateAiDraft` kind:treatment).
